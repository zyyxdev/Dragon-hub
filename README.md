# Dragon Hub

Scripts e ferramentas para Dragon Blox.

- `Scripts/ZYYX_Dumper_v9.lua` — dumper pós-update (agnóstico de versão do Knit, gera mapa de remotes)
- `Scripts/DB_Resolver.lua` — resolução de remotes em runtime
- `DragonHub.lua` — hub principal
- `Dados/Dumps/` — saída local do dumper (fora do repo)

Auto-sync: `~/bin/dbwatch start 15` commita e empurra cada mudança.
